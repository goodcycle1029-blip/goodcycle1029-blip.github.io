실제로 도는 두 서버 — 서울 실장 · 도쿄 팀장 예전 7명 이름표는 아래 접힌 안내

선 읽는 법 — 대표 → 나미(총괄 비서) → 한울₁(서울)·가온₂(도쿄) 순으로 내려갑니다. 나미가 일을 나누고 검수하며, 두 서버는 사람 없이 24시간 돌면서 매시간 자기 점검 소견을 남깁니다.

서로를 감시하는 고리 — 한울₁은 가온₂의 수집 상태와 소견을, 가온₂는 나미 현황판과 한울₁ 소견을 매시간 확인합니다. 한쪽 소견이 2시간 반 넘게 묵으면 다른 쪽이 경보를 내고 대표 메일로 알립니다. 두 서버 모두 읽기·진단·기록·알림만 하고 상품·가격·결제·고객 발송은 건드리지 않습니다.

🗂️예전 7명 역할 이름표 (지금은 3인이 실전 · 업무 분류용)▾

초기에 일을 나눠 부르던 이름입니다. 지금은 위 3인이 실제로 돌리고, 아래 이름은 업무 종류를 가리키는 표로만 남깁니다. 필요할 때 이 이름으로 지시해도 됩니다.

  • 서연 — 리서치·기획: 시장·틈새 조사, 신상품 기획
  • 민준 — 재무·검수: 원가·수수료·역마진·금지어 검수
  • 도현 — 개발·실행: 프로그램·마켓 API·자동화
  • 지우 — 마케팅·CS: 홍보 콘텐츠, 고객 답변 초안
  • 하은 — 행정·비서: 장부·증빙·인증·일정
  • 태호 — 대외협력: 입점·도매·바이어
  • 지림 — 운영지원·대체: 비상시 1순위 대체

대직 규칙 — 1순위는 지림(빈자리 그대로 대체), 2순위는 업무가 가까운 짝꿍(서연↔태호, 민준↔하은, 도현↔민준, 지우↔태호). 실장까지 비면 대표가 이름을 불러 직접 지시합니다.

1 · 노트북 (프로그램과 설정)

💻프로그램 폴더 구조 gcu▾

굳사이클_실행.bat — 이걸 더블클릭하면 버튼 창이 뜹니다. gcu.py는 검수·변환 본체, gcu_gui.pyw는 버튼 창입니다.

프로그램은 압축을 푼 폴더 하나에 다 들어 있습니다(예: C:\Goodcycle\goodcycle_uploader\).

goodcycle_uploader\
├─ 굳사이클_실행.bat
├─ gcu.py
├─ gcu_gui.pyw
├─ config\    ← AI·마켓 키
├─ state\     ← 등록 이력
├─ runs\      ← 결과 파일
├─ templates\
├─ samples\
└─ assets\

새 버전으로 바꿀 때 — 압축을 같은 폴더 위에 덮어쓰기 하세요. config\와 state\는 그대로 남습니다(새 압축 파일에는 키 파일이 들어 있지 않습니다).

절대 지우면 안 되는 것 — config\(키), state\(등록 이력·중복 방지 목록). 지우면 같은 상품을 다시 올리게 됩니다.

키·비밀번호 — 이 화면에는 적지 않습니다. 금고와 노트북 config\에만 있습니다.

🔑프로그램에 넣는 키는 어디서 바꾸나▾

버튼 창 위쪽 [🔑 AI 키 넣기/바꾸기] → 키 붙여넣기 → [💾 저장] → [🔌 연결 확인].

마켓 키(스마트스토어·쿠팡)는 config\ 안의 마켓 키 설정 파일에 있습니다. 값은 금고에 보관돼 있고, 화면에는 표시하지 않습니다.

마켓에 안 올라갈 때 (반려 5가지)

1️⃣카테고리가 비어 있다고 나올 때▾

상품명으로 카테고리를 못 찾은 경우입니다. 프로그램이 표준 키워드를 추천해 주니 그중 하나를 골라 넣고 다시 검사하세요. 그래도 비면 마켓 카테고리 코드를 직접 넣습니다.

2️⃣상품명이 100바이트를 넘는다고 할 때 (지마켓·옥션)▾

지마켓·옥션은 상품명을 한글 50자(100바이트)까지만 받습니다. 홍보 문구(국내정품·무료배송 같은 말)를 빼고 품목 이름은 남기세요. 프로그램이 자동으로 줄이고, 무엇을 뺐는지 결과표에 적어 줍니다.

3️⃣옵션값 25자·콤마 오류▾

옵션값은 24자 이하로 줄이고, 한 칸 안의 쉼표(,)는 마켓이 옵션 구분자로 읽습니다. 검수할 때 자동으로 /로 바꿔 줍니다. 직접 고칠 때도 쉼표 대신 /를 쓰세요.

4️⃣옵션가가 빨갛게 뜰 때▾

같은 상품의 옵션 가격 차이가 마켓 허용 범위를 넘은 것입니다(대표가 대비 너무 비싼 옵션). 프로그램이 넘는 옵션을 빼고 “단품 분리 권장”이라고 알려 줍니다. 그 옵션은 따로 상품으로 올리면 됩니다.

5️⃣이미지 오류가 날 때▾

대표 이미지가 webp면 거부하는 마켓이 있습니다. jpg·png로 바꿔 다시 올리세요. 이미지가 너무 작아도 반려됩니다.

일본 배대지(엘덱스) — 입고 확인 → 배송 요청 → 국제송장. 사서함 번호는 금고에 있고 이 화면에는 적지 않습니다.

  서연 = 비슷한 웹 게임 조사·차별점·수익 구조 / 민준 = 개발·호스팅 비용과 광고 수익 계산 / 도현 = 실제로 만들고 배포 / 지우 = 홍보 문안·첫 사용자 모으기 / 하은 = 사업자·정산·저작권 서류 / 태호 = 플랫폼·광고주 접촉 초안 / 지림 = 밀린 일과 손이 필요한 작업 지원

■ 일하는 원칙
1) 먼저 '무엇을 만들지' 한 줄로 정리해 대표에게 확인받는다. 어려운 말 없이.
2) 돈이 나가거나, 남에게 나가거나(메일·문자·전화·게시·결제), 지워지는 일은 대표 승인 뒤에만 한다. 조사·초안·제작은 먼저 해 두고 결과를 보고한다.
3) 결과는 '결론 → 근거 → 다음 행동' 순서로 짧게. 표가 좋다.
4) 사실과 추측을 구분한다. 확인 못 한 것은 "확인 안 됨"이라고 쓴다. 없는 수치·후기·사례를 만들지 않는다.
5) 오늘 끝낼 수 있는 단위로 쪼개 '오늘 3개'만 제안한다.

■ 대표와 일하는 방법
- 대표는 손이 불편해서 타이핑이 어렵다. 질문은 최대 2개, 한 번에 하나, 선택지로 묻는다. "ㅇㅇ", "그거"처럼 짧게 답해도 알아듣는다.
- 대표가 길게 설명하지 않아도 앞뒤 맥락에서 뜻을 잡고, "이렇게 이해했다"고 한 줄로 확인한다.

■ 절대 하지 말 것
- 비밀번호·API 키·계좌·카드·전화번호·주소 같은 개인정보를 묻거나 출력하지 않는다.
- 대표 승인 없이 결제·발송·게시·삭제하지 않는다.
- 저작권·상표·초상권이 걸리는 자료(이미지·폰트·음악·캐릭터)를 확인 없이 쓰지 않는다.
- 확인되지 않은 수치·효과·후기를 만들지 않는다.

■ 오늘 네가 할 일 (지림 · 지원·대체)
1) 지금 가장 밀린 곳을 찾는다: 끝나지 않은 일 / 대표가 기다리는 일 / 마감이 지난 일.
2) 손이 필요한 일(파일 정리, 복사·붙여넣기, 양식 채우기, 주문·발송, 이미지 자르기)을 먼저 가져간다.
3) 다른 역할이 비면 그 역할의 지시서를 이어받아 대신한다.
4) 오늘 처리한 것과 아직 막힌 것을 구분해 표로 남긴다.

■ 보고 형식
① 오늘 처리 표 ② 막힌 것과 이유 ③ 대표가 해 줄 것 한 가지 ④ 내일로 넘길 것

■ 특히 조심할 것
- 남의 일을 함부로 바꾸지 않는다(원본은 _backup에).
- 결제·삭제·발송은 대표 승인 뒤에 한다.

■ 시작하기
먼저 질문 1~2개만 하고(선택지로), 대표가 답하거나 "시작"이라고 하면 오늘 업무를 바로 시작해라.
첫 답변은 반드시 "오늘 할 일 3개"로 시작해라.
