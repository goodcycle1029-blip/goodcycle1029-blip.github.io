지금 바로 고치면 좋은 것부터 7가지로 나눠 보여 줍니다. 불빛이 빨강(반려·품절)인 마켓은 여기 목록에 이유가 있습니다.

📲 폰에 앱으로 설치하기

한 번만 해 두면 홈 화면 아이콘으로 바로 열립니다. 주소창 없이 앱처럼 뜨고, 인터넷이 잠깐 끊겨도 열립니다.

안드로이드 (크롬·삼성 인터넷)
  1. 이 화면을 연 브라우저 오른쪽 위 ⋮ (또는 ≡) 를 누릅니다.
  2. 앱 설치 또는 홈 화면에 추가를 누릅니다.
  3. 확인을 누르면 홈 화면에 내 마켓 현황판 아이콘이 생깁니다.
아이폰 (사파리)
  1. 사파리 아래쪽 공유 버튼(□↑)을 누릅니다.
  2. 목록을 내려 홈 화면에 추가를 누릅니다.
  3. 오른쪽 위 추가를 누르면 끝입니다.

위에 📲 홈 화면에 추가 버튼이 보이면 그 버튼을 눌러도 됩니다. 아이폰은 브라우저 메뉴로만 설치할 수 있어 버튼이 안내로 바뀝니다.

📥 마켓별 엑셀 받는 곳

마켓마다 메뉴 이름이 조금씩 다릅니다. 비슷한 이름을 찾아 상품 목록을 엑셀·CSV로 내려받으면 됩니다.

스마트스토어 상품관리 → 상품 조회/수정 → 상품 선택 → [엑셀 일괄작업] → 수정양식 다운로드
쿠팡 상품관리 → 상품 조회/수정 → [엑셀 대량 수정] → 엑셀 다운로드 요청 (가격·재고·판매상태)
G마켓 ESM PLUS → 상품 조회/수정 → 사이트 G마켓 선택 → 목록 오른쪽 위 [엑셀 다운로드]
옥션 ESM PLUS → 상품 조회/수정 → 사이트 옥션 선택 → 목록 오른쪽 위 [엑셀 다운로드]
11번가 상품관리 → 상품 조회/수정 → 판매상태 전체로 검색 → 오른쪽 위 [엑셀 다운로드]
롯데ON 판매자센터(partner.lotteon.com) → 상품관리 → 상품 조회 → 판매상태 전체로 검색 → [엑셀 다운로드]
받을 때 팁 — 판매상태를 전체로 놓고 받아야 반려·중지 상품까지 보입니다. ESM PLUS는 G마켓·옥션이 한 파일에 같이 들어 있어도 되고, 따로 받아도 됩니다. 파일 안에 사이트 칸이 있으면 그 값을 보고 G마켓·옥션을 나눠 셉니다.

📂 파일 넣는 법

  1. 현황판 탭 위쪽 [파일 고르기]를 누릅니다.
  2. 폰의 다운로드 폴더에서 받아 둔 .xlsx · .csv를 고릅니다. 여러 개를 한 번에 골라도 됩니다.
  3. 잠시 뒤 마켓별 불빛과 숫자가 채워집니다.

파일을 잘못 골랐거나 마켓을 잘못 알아보면, 넣은 파일 목록에서 마켓을 바꾸거나 ✕로 뺄 수 있습니다. 원본 파일은 지워지지 않습니다.

🚦 색과 불빛 읽는 법

회색 · 판매중(주문 전) — 상품을 올려 둔 상태입니다. 손볼 항목은 없지만 아직 주문이 왔다는 뜻은 아닙니다.
주황 · 확인 필요 — 중복 의심 · 원산지 누락 · 마켓 간 가격차(15% 이상), 또는 문제는 없는데 판매중이 0건
빨강 · 반려·품절 — 승인반려 · 재고 0인데 판매중 · 금지·과장 표현 · 가격 이상 중 하나라도 있음
초록 · 실제 주문·발송·배송 중 — 주문이 실제로 들어온 상태를 뜻합니다. 이 앱은 상품 목록만 읽으므로 초록불은 켜지지 않습니다(주문은 마켓 앱에서 확인).
⚪ 미등록 — 아직 그 마켓 파일을 넣지 않음

카드의 요약 줄을 누르면 한 줄 설명이 펼쳐집니다. 주황·빨강 불빛은 천천히 깜빡여 눈에 들어옵니다.

도넛 읽는 법 — 마켓 카드마다 동그란 도넛 가운데 숫자는 그 마켓 상품이 모두 몇 건인지를 보여 줍니다(전체 등록 1,240건처럼). 예전처럼 100%라고 적지 않습니다 — 상품이 다 올라가 있다는 것과 주문이 왔다는 것은 다르기 때문입니다. 도넛 색은 회색 = 판매중(주문 전), 주황 = 대기·확인, 빨강 = 반려·품절, 연회색 = 종료·기타입니다. 맨 위 전체 마켓 비교도 마켓마다 도넛 한 장씩 놓고 가운데에 전체 건수를 적었습니다.

🔧 손볼 곳 7가지

  1. 중복 의심 — 같은 마켓에 같은 상품이 두 번 등록
  2. 상품명 점검 — 최저가·1위·100%·효능 표현, 쓸 수 없는 문자, 100자 초과
  3. 재고 0인데 판매중 — 주문이 들어오면 취소·패널티로 이어짐
  4. 가격 확인 — 판매가가 비었거나 100원 미만
  5. 원산지 표시 — 비었거나 '기타'로 되어 있음
  6. 승인반려 — 반려 사유를 확인해 다시 올리기
  7. 마켓마다 가격이 다른 상품 — 같은 상품이 마켓 간 15% 이상 차이

점검 목록은 손볼 곳 탭 아래 [점검목록 CSV 저장]으로 받아 엑셀에서 하나씩 처리할 수 있습니다.

🔒 내 자료는 어디에 있나요?

엑셀 파일은 이 폰의 브라우저 안에서만 읽습니다. 어느 서버로도 보내지 않고, 로그인도 가입도 없습니다.

  • 파일과 분석 결과는 이 브라우저의 저장 공간(IndexedDB)에만 남습니다.
  • 앱을 껐다 켜도, 폰을 다시 시작해도 그대로 있습니다.
  • 인터넷이 끊겨도 마지막 화면은 열립니다.
  • 다른 사람 폰에서는 내 자료가 보이지 않습니다. 이 주소를 공유해도 각자 폰에 따로 저장됩니다.
지우고 싶을 때 — 아래 버튼을 누르면 이 폰에 저장된 파일과 결과가 모두 지워집니다. 마켓에 올라간 상품은 그대로입니다.

🧐 자주 막히는 곳

  • “머리글 줄을 찾지 못했어요” — 상품 목록이 아닌 파일이거나, 위쪽에 안내 문구만 있는 파일입니다. 마켓에서 상품 조회/수정 → 엑셀 다운로드로 다시 받아 보세요.
  • 예전 .xls 파일 — 엑셀에서 열어 다른 이름으로 저장 → Excel 통합 문서(.xlsx)로 저장한 뒤 넣어 주세요.
  • 상품이 0건 — 판매상태를 전체로 놓고 다시 내려받으세요.
  • 글자가 깨져 보여요 — CSV는 utf-8·euc-kr을 자동으로 알아봅니다. 그래도 깨지면 엑셀에서 CSV UTF-8로 저장해 보세요.
  • 파일이 너무 커요 — 40MB가 넘는 파일은 폰에서 열기 어렵습니다. 기간을 나눠 받아 보세요.
